Siege of Steel 2 — الإصدار الأسطوري

خطوات تشغيل اللعب الأونلاين (مرة واحدة فقط) في مشروع stor-7asson:
1) Build ← Realtime Database ← Create database (وليس Firestore فقط).
2) Authentication ← Sign-in method ← فعّل Anonymous.
3) Realtime Database ← Rules ← الصق محتوى database.rules.json ثم Publish.
4) انسخ رابط القاعدة من تبويب Data إلى databaseURL في firebase-config.js إن اختلف عن الافتراضي.
5) ارفع الملف على استضافة https — لا يعمل الأونلاين عند فتحه كملف محلي (content:// أو file://).
   الإعدادات مضمّنة الآن داخل index.html، فيكفي رفع index.html وحده.

الأغنية: الموسيقى المدمجة مولّدة داخل اللعبة. لاستخدام أغنيتك ضع ملف MP3
باسم theme.mp3 داخل مجلد music — تُشغَّل تلقائياً في البداية واللوبي وتتوقف داخل اللعب.

الأونلاين:
- اللعب مع الأصدقاء: أضف صديقاً بالـ ID ثم ادعُه إلى غرفتك.
- معركة مفتوحة: يدخل أي لاعب؛ كل لاعب يختار فريقه (أزرق/أحمر/أخضر/أصفر/منفرد).
  أعضاء الفريق الواحد حلفاء، وكل من هو خارج فريقك عدو.
